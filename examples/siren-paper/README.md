## Consistency with the current pipeline

This paper predates the code-enforced quality gates. It was not regenerated. Running the
current gates on `siren-paper.tex` (`sisyphus gate patterns|statistics siren-paper.tex`) gives
the results below, so the pipeline would send it back for revision.

**Formatting**
- The bibliography is a hand-written `thebibliography` block. The pipeline now writes
  `references.bib` from verified records only.
- `figures/architecture.pdf` is never included in the `.tex`.

**AI-pattern gate: fails** (13 hits in 3267 words, 3.98 per 1000; the limit is under 2)
- 1 em dash substitute: a spaced `--` in the conclusion (line 376)
- 6 inline-header lists (`\item \textbf{Name:} ...`) and 6 title-case subsection headings

**Statistics gate: fails** (6 errors)
- The abstract reports a 95% CI of [92.6%, 96.0%] for 94.3% accuracy. Table 1 reports ±0.9 for the
  same number, which gives [93.4%, 95.2%].
- The abstract reports RAG at 12.5pp, consensus at 8.9pp and the combination at 34.0pp. The body
  reports RAG at 15.3 points, consensus without RAG at 10.1 points, and uses 8.9pp for the
  SIREN vs BlockAgents gap.
- The abstract and conclusion say 72% fewer failures; the body computes 72.6%.
- The interaction effect is reported as p < 0.001 without a test statistic (line 299, warning).

**Citation gate: would fail** (needs network access to run; not run here)
- 6 bibliography entries are never cited: `llm_deliberation`, `suave_flashbots`,
  `cross_chain_sandwich`, `multi_agent_rl_cross_chain`, `agentic_consensus_l1`, `dealforge`.
- 4 entries have no authors: `agent_blockchain_survey`, `swarm_contract`, `cross_chain_sandwich`, `dealforge`.
- Several cited sources are blog posts, documentation pages or GitHub repositories (`near_intents`,
  `uniswapx`, `cowswap`, `rag_blockchain_agent`, `randao`, `tor_prop250`). They are not indexed by
  2 of Semantic Scholar, CrossRef, OpenAlex and arXiv, so the gate cannot verify them.
- `omniintent` is dated 2025, but its arXiv id 2603.04168 corresponds to March 2026.

**Content to check by hand**
- The abstract and dataset section mention 8 DeFi categories; Table 1 lists 6.
- Ethereum mainnet blocks 18,000,000 to 20,000,000 are dated "Feb to Aug 2025" in the dataset
  section. Those blocks were produced in 2023 and 2024.
- The evaluation uses a simulated multi-chain environment. The current pipeline requires every
  reported statistic to come from `analysis/statistics.json` produced by code in the run, and no
  analysis output ships with this example.
