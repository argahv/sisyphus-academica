Student's test rejected the true null in 1058 of 4000 datasets, a rate of 26.5\% (95\% CI [25.1\%, 27.8\%]). Welch's test rejected it in 216 datasets, a rate of 5.4\% (95\% CI [4.7\%, 6.1\%]). An analyst using Student's test at the 5\% level would therefore see a false positive in roughly one of every four comparisons of this shape.

The two tests disagreed on 842 datasets. In all of them Student's test rejected and Welch's test did not. There was no dataset where only Welch's test rejected. McNemar's test on these discordant pairs gives $\chi^2(1) = 842.00$, $p < 0.001$. Welch's rejection rate did not differ from the nominal level ($z = 1.16$, $p = 0.25$), and its interval contains 5\%.
