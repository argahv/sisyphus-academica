We drew 4000 pairs of samples from normal distributions with equal means. The small group had $n = 10$ and standard deviation 3. The large group had $n = 40$ and standard deviation 1. For each pair we ran Student's test with pooled variance and 48 degrees of freedom, and Welch's test with Welch-Satterthwaite degrees of freedom~\citep{welch1947generalization}. A test rejected when its two-sided $p$-value fell below 0.05. Because the true difference was zero, every rejection is a Type I error.

We report each rejection rate with a Wilson score interval~\citep{wilson1927probable}. Both tests ran on the same datasets, so we compared their rejection rates with McNemar's test for paired proportions~\citep{mcnemar1947note}, which uses only the datasets on which the tests disagree. We also compared Welch's rejection rate with the nominal 0.05 level using a one-sample $z$ test for a proportion. The simulation uses Python's standard library with the random seed fixed at 2026.
