Student's two-sample $t$-test assumes equal group variances, yet many analyses apply it to groups of different size and spread. We measured how often the test rejects a true null hypothesis when the smaller group has three times the standard deviation of the larger one. Across 4000 simulated datasets with no true difference, Student's test rejected the null in 26.5\% of cases, while Welch's test rejected it in 5.4\%, close to the nominal 5\% level. The two tests disagreed on 842 datasets, and in every one of them Student's test was the one that rejected. For unequal group sizes, Welch's test should be the default.
